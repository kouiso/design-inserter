# Design Inserter Notices

Design Inserter bundles HTML/CSS/SVG Design Parts collected from an external source.

- Source: https://pote-chil.com/css-stock/ja
- Each bundled part keeps its original `sourceUrl` in `data/css-stock-parts.json`.
- Rendered frontend output includes an HTML comment with the part source URL.
- The design parts source states that listed source code may be used on websites/blogs, and that republishing the code itself in another medium requires a link to the relevant page and clear source attribution.

The design parts source does not explicitly grant paid redistribution of the collected source code as a WordPress plugin. Get explicit permission from the source before selling or publicly distributing paid packages that include the bundled design parts.

Some design parts include icon artwork sourced from Remix Icon. Remix Icon is licensed under the Remix Icon License v1.0:
